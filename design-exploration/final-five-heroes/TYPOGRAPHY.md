# Typography and color direction

The type in the PNGs is generated imagery. These are proposed build pairings, to be set using actual font files and refined optically during implementation.

| Concept | Suggested display family | Supporting family | Color system |
| --- | --- | --- | --- |
| Forest | Barlow Condensed, a strong condensed display treatment | Manrope | Sand #EDE4D5, forest #0D4537, limestone #F4F0E6, chartreuse #C9DB76 |
| Cobalt | Barlow Condensed, a controlled bold/oblique treatment | Manrope | Porcelain #F3F0EA, ink #111820, cobalt #2F52D7 |
| Ember | Barlow Condensed, a bold editorial treatment | Manrope | Burnt orange #D34A22, vermilion #E66B35, ivory #F6E9D4, charcoal #171A18 |
| Pace | Archivo Black, with carefully composed lowercase name forms | Manrope | Butter #F2E9C8, ink #181C1D, cobalt #3359CC, cream #FAF6EA |
| Alloy | Space Grotesk, with an optional small Instrument Serif accent | Manrope | Black #0D1011, white #EDECE6, gunmetal #6F7574, amber #D6A267 |

Official family references: [Barlow Condensed](https://fonts.google.com/specimen/Barlow+Condensed), [Manrope](https://fonts.google.com/specimen/Manrope), [Archivo Black](https://fonts.google.com/specimen/Archivo+Black), [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif).

These pairings are design judgments for the build, not a claim that the generated screenshots use the exact font files. Size, tracking, baseline placement, masking, and the relationship to the portrait are central to the identity.

Keep a small type hierarchy: one large display treatment, one clear role label, one supporting line, and navigation/action text. Use the accent color to guide attention.
