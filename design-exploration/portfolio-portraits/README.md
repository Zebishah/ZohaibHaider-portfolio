# Three-piece-suit portfolio portraits

Five AI-generated portrait treatments made with the built-in image_gen tool, using Zohaib's supplied personal photographs as identity references. These are portrait assets for choosing a portfolio hero image; no website code has been changed.

| File | Treatment | Intended use |
| --- | --- | --- |
| 01-charcoal-cutout.png | Charcoal suit, neutral studio lighting | Transparent hero cutout over ivory, sand or a colored surface |
| 02-forest-editorial.png | Forest-green suit, warm architectural studio | Forest/cream portfolio direction |
| 03-midnight-cutout.png | Midnight-navy suit, subtle cobalt edge light | Transparent hero cutout for a blue/ivory direction |
| 04-ember-cinematic.png | Black suit, charcoal and copper studio | Dark or orange cinematic direction |
| 05-platinum-editorial.png | Gray pinstripe suit, monochrome studio | Minimal editorial direction |

The jacket, waistcoat and trousers form a matching three-piece suit in each treatment. The two cutouts are requested with actual transparent backgrounds. Keep the original PNG files to preserve alpha and fine hair details. Use `object-fit: contain` when the whole silhouette should remain visible.

The exact generation prompts, reference paths and background settings are saved in [prompts.json](prompts.json). File sizes and dimensions are recorded in manifest.json after generation.
