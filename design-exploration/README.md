## Original concept 01: Signal

**Image:** `01-signal.png`

Charcoal, warm white, and pale lime. Oversized typography sits beside a dimensional glass software stack. The three layers represent interface, intelligence, and infrastructure.

**Proposed signature interaction:** hover or select a layer to reveal a real project implementation. Scrolling separates the layers and introduces a case study. A demo request can illuminate its path through UI, API, model, and database.

**Page sequence:** introduction → selected projects → an interactive request journey → AI experiments → approach → contact. Include conventional project links alongside the visualization.

**Why it fits:** makes full-stack and AI work visible in one coherent visual language. My strongest overall recommendation for a dramatic, professional portfolio.

## Original concept 02: Atlas

**Image:** `02-atlas.png`

Warm ivory paper, ink-black serif typography, and ultramarine annotations. A technical monograph with an exploded architectural diagram and a numbered project ledger.

**Proposed signature interaction:** open a project as an engineering field note. Visitors can switch between product screenshots and its annotated system architecture, then follow an example request through the stack.

**Page sequence:** editorial introduction → project index → annotated case studies → engineering notes → personal background → contact.

**Why it fits:** gives technical depth and clear writing the same prominence as the visual design. My choice for a distinctive light theme and readable case studies.

## Original concept 03: Little Lab

**Image:** `03-little-lab.png`

Cream, terracotta, and teal. A tactile miniature workshop contains a monitor, server rack, AI experiment instrument, and notebook. Crisp surrounding typography provides immediate access to work.

**Proposed signature interaction:** click the monitor for products, the instrument for AI demos, and the notebook for background. The scene can change subtly between work and play modes.

**Page sequence:** workshop introduction → selected projects → experiment shelf → how I build → story → contact.

**Why it fits:** the most playful and personal of these directions. The quality depends on carefully authored 3D art and smooth interaction.
